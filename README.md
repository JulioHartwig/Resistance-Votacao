# Resistance – Votação da Missão

Aplicação web para votar **sucesso** ou **falha** em segredo no jogo The Resistance (5 jogadores).
Todos votam no mesmo celular, um de cada vez.

- Placar das 5 missões (missões 1 e 4 com 2 pessoas; 2, 3 e 5 com 3 pessoas)
- Placar de equipes recusadas: ao chegar a 5 recusas seguidas, os espiões vencem
- O contador de recusas volta a zero depois que uma missão é votada
- O placar fica salvo no navegador (localStorage)
